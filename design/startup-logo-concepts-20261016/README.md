# Laintas CLI 开屏 Logo 设计提案

仅用于选型，未更改现有开屏。推荐方案 01。最终需要在目标终端校准 Unicode 字宽；纯 ASCII 的 L> 可作为兼容版本。

## 01 终端签名

推荐 · 品牌辨识与日常使用兼顾。让 L 与提示符组成标记，右侧用小写字标。

```text
 ╷       ╲
 │        ❯   laintas
 ╰────   ╱
  cli · agent main
```

3 行 · 短而清晰 · 可延伸为状态栏标记

## 02 像素字标

醒目 · 适合强调 CLI 的开场。保留完整名称，以更实的笔画建立记忆点。

```text
█    ▄▀▀▄ ▀█▀ █▄  █ ▀▀█▀▀ ▄▀▀▄ ▄▀▀▀
█    █▄▄█  █  █ ▀▄█   █   █▄▄█  ▀▀▄
█▄▄▄ █  █ ▄█▄ █   █   █   █  █ ▄▄▄▀
  cli · agent main
```

3 行 · 黑白也醒目 · 更有终端工具的气质

## 03 精修线体

克制 · 延续现有字标。调整字距与横竖笔画，保留熟悉的视觉性格。

```text
╷    ╭─╮  ╷  ╷ ╷  ╺┳╸  ╭─╮  ╭─╮
│    ├─┤  │  │╲│   ┃   ├─┤  ╰─╮
╰──  ╵ ╵  ╵  ╵ ╵   ╵   ╵ ╵  ╰─╯
  cli · agent main
```

3 行 · 变化温和 · 适合直接升级当前开屏

## 04 工具铭牌

极简 · 让工作区成为主角。名称收进一块窄铭牌，像工具上的产品刻印。

```text
┌─────────────────────────────┐
│  L>  laintas                │
└─────────────────────────────┘
  cli · agent main
```

3 行 · 边界明确 · 窄终端也容易排版
