# CLI TUI audit — 2026-11-03

Baseline: `7d17c76` (`chore: snapshot workspace before CLI TUI improvements`). Existing tracked work and the pending consistency regression tests were committed before these edits. Existing backup and build-scratch directories were excluded.

## Coverage and boundaries

- 74 primary slash commands; 84 command names including aliases exercised through a real CLI PTY.
- All 74 primary commands exercised with the isolated scenario recorded below. Account storage and the working directory were task-local; remote connections were disabled.
- 900 help renderings: the overview and every primary command, at 38, 60, 80 and 120 columns, in dark, light and mono themes. Every line stayed within its cell budget.
- All six bundled extension packages loaded in an isolated runtime. `/blindpick`, `/canvas`, `/issues`, `/pow`, `/swebench` and `/whatsapp` expose help without invoking their handlers and appear in the command palette.
- Launch flags are covered by the existing parser/entry suite. The audit retains the Python/Rich/prompt_toolkit stack.
- Live OAuth, paid inference, account mutation and extension installation/publication were not sent to production. Those paths were checked through help, validation and the existing mocked integration tests.

## Changes

- The palette returns a plain command rather than Rich markup; it also includes registered extension commands and searches descriptions.
- A standalone `--help` or `-h` works before command validation and before the REPL intercepts session commands. Quoted values and flags within tool/shell arguments keep their ordinary meaning.
- Help shows each subcommand, lists concise command names in the overview, and switches to stacked rows on narrow screens. Agent/session/reset descriptions state the effect more directly.
- Filtering cannot confirm an invisible row. Enter on an empty result keeps the filter editable. Searchable pickers reserve ordinary letters for typing and use Alt+letter for actions.
- PageUp/PageDown navigation, a fixed footer, visible counts and cell-based clipping keep choices and cancellation discoverable during resize and long-row scrolling. Rich styling survives the marquee.
- User navigation/typing cancels an automatic confirmation countdown. An unchanged countdown still confirms its intended default.
- Pickers and resource browsers follow dark/light/mono and NO_COLOR. Resource footers preserve Esc in narrow layouts; /config reset restores the configured default theme.
- Workflow Studio puts exit/cancel/help before secondary actions in navigation, help, inspection, running and result states below 72 columns.
- Both shared UI components acquire terminal ownership and restore it. The nested CLI SIGTERM/SIGHUP hard-exit path restores terminal state before bypassing finally/atexit.
