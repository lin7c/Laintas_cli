# Web Research

Use web tools when the answer depends on external or current information:

- Search first when facts may have changed, the user asks for latest/current info, or a specific URL/document is referenced.
- Prefer primary sources: official docs, specs, source repos, release notes, papers, or vendor pages.
- Cite sources in the reply when web evidence affects the answer.
- Do not over-fetch. Read the smallest relevant page or section first.
- For technical API behavior, trust official documentation over blog posts.
- If sources disagree, state the discrepancy and which source you relied on.
