# Laintas CLI v2.0.0

Laintas CLI v2.0.0 is now available. This is the first stable release of the new series: the beta line (package versions 1.32.5b1-b5) ends here, and the formal release line moves to 2.0.0 - above every previously published version, so every existing install, beta or stable, is offered this update through /v update as usual.

- Performance pass over startup and the agent loop. A lightweight entry point answers --version and --help without loading the interactive runtime; the pre-send context check no longer recounts the whole conversation repeatedly; per-turn context snapshots and long-session saves avoid full rescans.
- Context handovers reach the terminal. A context handed over through the Laintas inbox (context_handed) can be opened in the CLI and continued as a local session, fitted and scrubbed by the built-in Context Kernel v1. Only the context travels; the environment stays this machine's own.
- The Issues extension reaches 0.2.4: public answers and personal tasks in the terminal, with durable deduplication for gateway tool executions.
- AUX follow-through: memory consolidation now also runs when a session goes idle, alongside compaction-time consolidation.
- Windows: the terminal window host creates the runtime temporary directories before the shell starts, so a fresh install no longer fails its first launch. This ships with the next Windows build on its own channel.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
