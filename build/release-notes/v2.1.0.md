# Laintas CLI v2.1.0

Laintas CLI v2.1.0 adds background-agent delegation and approval handling, and softens the secret check from a hard block to a confirm step.

- New: `@name task` hands work to another agent without leaving the foreground conversation, both at the prompt and while a turn is running. An idle agent starts the task in the background; a busy one receives the line as an update. When background work finishes, a message waits behind the prompt (Alt+0, `o`, or `/messages read <n>`); opening it switches to that agent's conversation.
- New: a background agent's approval is asked at the main CLI prompt instead of timing out unanswered. The broker hands the question to the main loop, keeps the half-typed input line, and asks each request exactly once. `/agents` shows which agent is waiting for approval.
- Changed: `/agents` is now a read-only view of the terminal's persistent agents, with a detail page per agent (responsibilities, setup, current work, sub-agents, recent tasks). Nothing typed in the view reaches an agent; Enter selects the agent that leaving the view switches to.
- Changed: the secret check now warns before it blocks. Text that looks like a password or API key gets a one-time warning: press Enter again to send it anyway (remembered by digest for this process only; flagged text is still never written to saved history), or edit it out first. If the check itself is unavailable, sending still fails closed.
- Performance: the terminal does less repeated layout work, and End-key navigation stays responsive in long transcripts.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel; Windows users can update in place with /v update.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
