# Laintas CLI v2.2.2

Laintas CLI v2.2.2 upgrades ACP mode (`laintas-cli --acp`) for Laintas ACP Console and ACP editors, bundling the ACP SDK into the standard release binaries.

- New: native `/model` command in ACP sessions (`AvailableCommandsUpdate`) to list backend models, switch by index or model ID, or reset to auto-routing with `/model reset`, while bypassing local direct-route overrides when a session model is selected.
- New: live execution plan updates (`AgentPlanUpdate`) streamed to ACP clients whenever tasks are created or updated during a turn.
- New: `agent-client-protocol` is now included in core requirements and PyInstaller Linux/macOS bundles so `laintas-cli --acp` works out of the box without a separate `pip install`.
- Fixed: concurrent tool calls in ACP mode now track completion status independently by `call_id` and finalize any open tool calls when a turn ends.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel; Windows users can update in place with /v update.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
