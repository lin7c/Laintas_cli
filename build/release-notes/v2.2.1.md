# Laintas CLI v2.2.1

Laintas CLI v2.2.1 gives image and video generation their own axes in /model: pick the default model for each kind, or switch a kind off entirely.

- New: /model image [off|on|status|<model-id>|reset] chooses the default image generation model from the gateway's media catalogue -- the picker marks the gateway default and any of your own Compute machines, and an id can also be typed directly. Picking a model enables image generation; reset returns to the gateway default.
- New: /model video [off|on|status|<model-id>|reset] does the same for video generation. The two kinds are independent axes: switching one off never touches the other.
- New: switching a kind off is a real off. media.generate_image / media.generate_video is removed from the tools offered to the agent, and a call that still arrives is refused before any request is sent. The saved model is kept, and /model image on (or /model video on) resumes with it.
- Changed: the generation tools now send your chosen model to the gateway. If the gateway refuses it (unknown, or switched off upstream), that error is reported as-is -- the call is never silently re-routed to the default model. With no model chosen, no model is sent and the gateway default applies as before.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel; Windows users can update in place with /v update.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
