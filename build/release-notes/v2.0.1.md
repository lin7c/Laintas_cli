# Laintas CLI v2.0.1

Laintas CLI v2.0.1 is a hotfix for the message security check.

- Fix: on installs whose bundled runtime is missing the detect-secrets package (notably the Windows beta v5 installer), the local secret-input check failed to load its deep-scan detectors and then refused to send every message ("local security check unavailable"). The deep-scan layer is now additive: a detector that cannot be imported or constructed is skipped, and the built-in screening (private keys, token prefixes, JWTs, credential fields) continues to run on its own. Ordinary messages send normally; real credentials are still blocked. If the core screening itself fails, the check still fails closed as before.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel; affected Windows users can update in place with /v update.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
