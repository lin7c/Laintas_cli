# Laintas CLI v2.2.0

Laintas CLI v2.2.0 makes local usage accounting reconcilable with your account, attributes every call to the agent that made it, and surfaces extension handlers that fail or run slowly.

- Changed: usage records move to format v2. Each record now carries the gateway's billing detail -- funding source (personal, subscription, seat or organization), membership credits, the ledger transaction id, and reasoning and cache-write token counts -- so a line in /usage can be matched against your account history. A cost of 0 paid in credits is no longer indistinguishable from a call metered elsewhere, whose cost is recorded as unknown rather than free.
- New: every usage record is attributed to its session, run and agent. The agent loop charges a calling agent from the local record even when a backend sends no billing metadata, and per-agent input/output token counters now survive a restart.
- New: image and video generations are recorded in the same local usage ledger as chat calls, with their billing detail.
- Changed: a long-lived CLI process no longer keeps every usage record in memory; the in-process session view is bounded and session totals are maintained as an aggregate.
- New: extension observer health. Event handlers that raise or take longer than 50 ms are counted per extension, and /extensions reports the failures and slow calls instead of letting them fail silently.
- Changed: models Laintas deploys on its own rented compute are labelled laintas-model in the model picker, separate from Laintas Supply, Activated and Third-party Supply.

Packages: Linux amd64/arm64, macOS Intel/Apple Silicon, Debian amd64 and source. Windows installers use their separate release channel; Windows users can update in place with /v update.

Download and install: https://cli.laintas.com/
Existing users can update with /v update.
